**Идентификаторы:** учебник `history-rus-8`; материалы `history-rus-8-intro`, `history-rus-8-p1-2` … `history-rus-8-p53-54`,

Текст запрашивается по тройке (предмет, учебник, материал), поэтому § 2 одного учебника не может открыть § 2 другого.

## Порядок выпуска (только с разрешения владельца)

Порядок важен: сайт показывает материалы с `ready: true`; если опубликовать сайт раньше текстов, конспекты нового учебника
откроются с ошибкой «не найдено».

1. **Тексты в базу.** SQL вставки (42 строки, upsert только по ключам `history-rus-8`) хранится вне репозитория:
   один файл (~575 КБ) или 7 частей по ~80 КБ для MCP `execute_sql`. Проверка после записи:
   ```sql
   select count(*) from private.library_paragraphs where book_id = 'history-rus-8';            -- 42
   select count(*) from private.library_paragraphs;                                             -- 181
   select paragraph_id, encode(sha256(convert_to(content::text, 'UTF8')), 'hex')
     from private.library_paragraphs where book_id = 'history-rus-8' order by paragraph_id;     -- = манифест
   ```
   Прежние 139 строк сверить с `v62-library-manifest.tsv` и `v64-peryshkin-manifest.tsv`.
2. **Справочник аналитики:** применить `20261114120000_v68_history_russia_catalog.sql` → 211 строк, `retired` = 0.
3. **Сайт:** слить `release/v68` в `main` (GitHub Pages). Через 1–3 минуты: `app.js?v=68`, `konspekt-v68`.
4. **Проверка на телефоне:** Библиотека → 8 класс → История → два учебника; новый — «42 конспекта», «5 глав»; открыть
   введение, § 7–8, итоги главы III, заключение.

Повторное применение шагов 1–2 безопасно: без изменений ничего не переписывается, ничего не удаляется.

## Как сделаны конспекты

- Полного текста учебника 2026 г. в открытом доступе нет (магазины дают только карточку книги). Обходить ограничения доступа
  и использовать неофициальные копии нельзя, поэтому конспекты **написаны самостоятельно** по темам из оглавления и
  проверенным историческим сведениям. Это **не пересказ** страниц учебника и не цитаты из него.
- В каждом конспекте есть пометка: «Конспект составлен самостоятельно по теме параграфа из оглавления учебника и проверенным
  историческим источникам: полный текст учебника для сверки был недоступен…».
- Вопросы «Проверь себя» — тренировочные, с пометкой «Это не вопросы из учебника».
- Цитаты — только общеизвестные и проверяемые: Воинский устав 1716 г., «Морским судам быть», Пушкин («Полтава», «Капитанская
  дочка», о Ломоносове), Лермонтов («Бородино»), речь Александра I на польском сейме 1818 г.
- Формат тот же, что у прежних конспектов истории (StudyContent v1, `classic-2`): «Главное», разделы, таблицы,
  «Причина → следствие», определения, справочники терминов, дат и личностей, «Запомни», вывод, «Проверь себя».
- Даты XVIII в. — по старому стилю, у ключевых событий в скобках — по новому.
- Опорные источники: Большая российская энциклопедия; федеральная рабочая программа и историко-культурный стандарт по истории
  России (8 класс: «Россия в XVIII — начале XIX в.: от царства к империи»); общепринятые справочные данные о датах, договорах
  и сражениях. Сведения об издании: карточки книги в магазинах «Лабиринт» и «Читай-город».
