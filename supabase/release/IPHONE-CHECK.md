# Проверка v58 на реальном iPhone (без AI) — 15–20 минут

Нужно: iPhone с Safari, второй телефон или компьютер, 1 код с меткой `smoke` (шаг 5 V58-RELEASE.md).

| # | Действие | Ожидается |
|---|---|---|
| 1 | Safari → сайт; потянуть вниз для обновления | на «О приложении» и в коде страницы сборка 58 (экран «Ранний доступ» с полем кода и кнопкой «Создать аккаунт») |
| 2 | Ввести неверный код `ABCD-EFGH-JKMN` | «Код не подошёл…», поле не очищено |
| 3 | Ввести код `smoke` (можно строчными, с пробелами) → «Создать аккаунт» | экран «Аккаунт создан»: ID `KN-…`, ключ из 4 групп |
| 4 | «Копировать» у ключа → вставить в Заметки | ключ вставился целиком |
| 5 | Закрыть Safari (смахнуть), открыть снова | снова экран ID и ключа (не потерян) |
| 6 | Отметить «Я сохранил ID и ключ» → «Продолжить» | главная, «Остался 1 конспект»; библиотека открывается |
| 7 | «Я» | виден ID и «Выйти» |
| 8 | «Поделиться» → «На экран Домой», открыть с иконки (PWA) | приложение открыто, тот же ID в «Я» |
| 9 | Второе устройство: «У меня есть ID и ключ» → ID и ключ | вход, тот же ID |
| 10 | iPhone: «Выйти» → «Войти» с ID и ключом | вход снова работает |
| 11 | Авиарежим → открыть библиотеку | открывается; создание конспекта не предлагается делать без сети |
| 12 | Повторно ввести тот же код `smoke` на втором устройстве (гостем) | «Этот код уже использован…» |
| 13 | Камера (вкладка «Фото») | открывается; **конспект не создавать** (AI выключен) |

После проверки: удалить тестового пользователя (Dashboard → Authentication → Users), записать результат.
Любое расхождение в шагах 3–10 — не раздавать коды, сообщить.
