Правила (автоматически, без переписывания текста):
- **Без изменения слов:** разметка `[p:…]`/`[d:…]` ставится только вокруг уже существующих имён (по справочнику личностей
  самого конспекта) и дат; абзац длиннее 430 знаков делится на два по границе предложения.
- **Карточки определений** — текст берётся дословно из справочника терминов того же конспекта; если термин уже раскрыт
  в тексте («**термин** — …»), карточка не добавляется.
- **Без дублей «Вывода»:** итоговый «Вывод» в приложении и так показывается у каждого конспекта.
