## Как сделаны конспекты

- Полного текста учебника для сверки не было. Конспекты **написаны самостоятельно** по темам из оглавления и программе
  курса физики 7 класса; это **не пересказ** страниц учебника и не цитаты из него. В каждом конспекте есть пометка об этом.
- Формулы — отдельными блоками «Формула» с расшифровкой обозначений и единиц СИ (v = s / t, ρ = m / V, F = mg, F = kx,
  P = mg, F = μN, R = F₁ ± F₂ и др.); индексы (Fтяж, vср) показываются нижними.
- Примеры задач помечены как составленные для пояснения, «не задания из учебника»; вопросы «Проверь себя» — тренировочные.
- Лабораторные работы: цель, оборудование, ход работы, таблица для измерений и вывод — **без выдуманных результатов
  измерений**: в таблицах пустые графы «(измерь)», «(вычисли)».
- Формат тот же, что у конспектов физики 8 класса (StudyContent v1, `classic-2`).
