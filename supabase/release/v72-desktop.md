# v72 — версия для компьютера (ПК) и установка как приложение

Только интерфейс (index.html, app.js, desktop.css, manifest.json, service-worker.js, иконки-скриншоты).
Supabase, функции, подписки, лимиты, авторизация и тексты 288 конспектов не менялись.

## Что изменилось на компьютере (окно от 1024 px)
- Нижняя панель вкладок становится боковой (логотип, Главная / Библиотека / Фото / Я) и остаётся на экранах чтения и «Новый конспект».
- Рабочая область занимает ширину экрана с пределом (1120 px; 1280 px на очень широких мониторах), карточки — адаптивной сеткой.
- Чтение параграфа: оглавление слева и закреплено при прокрутке, текст — колонка до 760–800 px.
- «Новый конспект»: место для перетаскивания фото, кнопка «Выбрать файлы», вставка скриншота Ctrl+V; не-рисунки не принимаются с понятным сообщением; бросок файла мимо не открывает его вместо приложения.
- Нижние листы становятся окнами по центру; Esc закрывает окно или возвращает «Назад» на экранах чтения и библиотеки.
- Кнопка «Установить приложение» в боковой панели — только когда браузер (Chrome/Edge) сам предлагает установку.

Телефон и окно уже 1024 px — без изменений (скриншоты 390×844 до и после совпадают побайтово).

## PWA
manifest: id/start_url/scope `/konspekt-app/`, standalone, иконки 192/512 + maskable, скриншоты wide/narrow, описание.
service worker `konspekt-v72`: старые кэши удаляются при активации, обновление — как в v66–v71 (network-first, updateViaCache none).
